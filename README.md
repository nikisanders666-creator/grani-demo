# ГРАНИ — студия вокала Анастасии Мельниковой

Адаптивная демонстрационная версия сайта для просмотра и согласования дизайна.

## Файлы проекта

```text
index.html                   — HTML-разметка и структурированные данные Schema.org
css/style.css                — основные стили
css/responsive.css           — мобильные и планшетные стили
js/main.js                   — навигация и модальное окно контактов
assets/anastasia.jpg        — портрет преподавателя
assets/grani-logo-transparent.png — логотип
.nojekyll                   — настройка публикации GitHub Pages
```

## Как разместить на GitHub Pages

1. Откройте репозиторий `nikisanders666-creator/grani-demo`.
2. Перейдите в **Add file → Upload files** (для пустого репозитория — **uploading an existing file**).
3. **Распакуйте ZIP локально и загрузите все файлы и папки** в корень репозитория: `index.html`, `css/`, `js/`, `assets/`. Архив ZIP не нужно загружать как единственный файл.
4. Выберите **Commit changes**.
5. Откройте **Settings → Pages**, выберите **Deploy from a branch** → **main** → **/(root)**, затем **Save**.
6. После публикации проверьте: `https://nikisanders666-creator.github.io/grani-demo/`.

Сайт статический: без серверных форм, календаря, регистрации и базы данных. Навигация, меню, модальное окно, ссылки и адаптивный дизайн работают в браузере.
